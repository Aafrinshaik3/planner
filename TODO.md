# Celebrate delivery checklist

## Event workspace supports planning weddings, birthdays, and community events
- [ ] Users can create and edit an event plan with event type, date, location, guest count, budget, theme, and preferences.
- [ ] The workspace is responsive and usable on desktop and mobile planning workflows.

## Dashboard summarizes planning progress and next actions
- [ ] Dashboard summarizes planning progress, upcoming milestones, budget status, and outstanding vendor tasks.
- [ ] Users can move between overview, budget, timeline, vendors, and ideas without losing the active plan.

## Budget manager keeps spending decisions clear
- [ ] Budget categories show estimated and actual costs, payment status, category totals, and remaining-budget calculations.
- [ ] Users can add a budget category and see totals update immediately.

## Timeline and vendor checklist make execution actionable
- [ ] Timeline shows dated tasks in chronological order with deadline, owner/area, and completion states.
- [ ] Vendor checklist is organized by relevant categories with status tracking, notes, and due dates.
- [ ] Users can complete or reopen timeline and vendor tasks.

## Personalized idea generator turns event details into suggestions
- [ ] Ideas are tailored to event details, budget, theme, audience, and preferences.
- [ ] Users can generate, review, and save selected suggestions into the event plan.
- [ ] The server uses the managed LLM when available and retains a useful fallback when unavailable.

## Requested handoff deliverables
- [ ] Functional web app is published at a public URL.
- [ ] Public GitHub repository is connected or provided and remains under 10 MB.
- [ ] Walkthrough demo video is provided and stays under 4 minutes, showing key workflows.
